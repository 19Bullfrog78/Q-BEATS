struct Section: Codable, Identifiable {
    // ⚠️ Tech Debt TD-1: rinominare in SongSection prima di Fase 2
    var id: UUID

    var id: UUID
    var name: String
    var sections: [Section]

    var id: UUID
    var name: String
    var date: Date
    var songIDs: [UUID]

struct BacktrackFile: Codable, Identifiable {
    var id: UUID
    var filename: String
    var displayName: String

    // B7 — Metronomo adattivo:
    var tempoMap: [TempoPoint]?

enum MetronomeMode: String, Codable {

    case fixed      // BPM fisso per sezione (DEFAULT — comportamento attuale)
    case off        // audio+flash spenti, clock C++ gira sempre
}

struct AppSettings: Codable {
    var accentVolume: Double = 1.0

    var ch4Volume:    Float  = 0.0

// DA AGGIUNGERE in Fase 2
struct SectionSeparator: Codable, Identifiable {

## Vista LIVE — Spec complete

### Grid verticale fissa

```
8%  header
10% slot metronomo
8%  bar counter
4%  micro bar
35% giant text (teleprompter)
4%  macro bar
10% POI
21% transport
```

### Header

```
[ ← BACK ]  [ LED·LED·LED  {song.name}  ·  {bpm}[🔒]  ·  {time sig} ]  [ SVG MUTE ]
```

- `song.name` — JetBrains Mono 700, 28px
- BPM — JetBrains Mono 400, 17px. Lucchetto SVG se `backtrackFilename != nil` (opacity 0.45)
- Time sig — JetBrains Mono 400, 15px
- Mute button top-right: SVG speaker. Attivo = onde sonore bianco 85%. Muto = barra diagonale ambra `#f5b820`
- 3 LED 5px, invisibili se non attivi
- Stato STOPPED: aggiunge separatore `·` + label "STOP" JBMono 600, 10px caps, opacity 0.35

### Slot metronomo

N slot = beatsPerBar. Flash singolo frame ~16ms, no decay, no easing.
- Accento: `#d43f00`
- Beat: `rgba(255,255,255,0.85)`
- Subdivisione: `rgba(255,255,255,0.20)`
- Off: `rgba(255,255,255,0.08)`

SubdivisionMultiplier = audio-only, zero impatto visivo.

### Bar counter

"Battuta X di Y". Display "— / —" se total ≤ 0.
- Count-in / Standby → "— / —"
- Loop ∞ → "Battuta X di ∞"

### Micro bar

Segmentata N segmenti = N battute della sezione corrente.

### Giant text (teleprompter)

`Section.name`. Se vuoto → BPM sezione come fallback. Mai coesistenti.

### Macro bar

Segmentata N segmenti = N sezioni canzone. Fill avanza segmento per segmento (semantica piena, non decorativa).
Loop ∞ → si ferma sull'ultimo segmento.

### Zona POI

- Sezione successiva stessa canzone → `POI: {nextSection.name}`
- Ultima sezione + canzone successiva → `FINE · NEXT SONG: {nextSong.name}`
- Ultima sezione ultima canzone → zona vuota
- Handle mixer: barretta 32px×3px `rgba(255,255,255,0.20)` centrata in basso nella zona POI

### Transport

Tasti: Play/Stop · Loop · KILL BASE · EMERG

**KILL BASE — 3 stati:**
- Disabled: `!hasBacktrack` → opacity 0.3
- Attivo: bianco, tappabile
- Killed: testo ambra `#f5b820` lampeggiante sine ~1.5s (opacity 0.5→1.0)
- Glyph: "KILL\nBASE" due righe, JBMono 600, size 13

**PLAY/STOP:** `▶` fermo → `■` in play. Mai "⏹". Non esiste PAUSA.

**EMERG:** sempre attivo, mai disabilitato, mai opacity ridotta.

**Overlay mixer:**
- Trigger: swipe DOWN dalla zona POI
- Copre SOLO Transport 21% — teleprompter/barre/POI sempre visibili
- Background `rgba(255,255,255,0.05)`, no blur
- 4 slider verticali: CLICK / BACKT / CH3 / CH4
- CH3/CH4 grayed out in modalità Base hardware
- Handle barretta nella zona POI come affordance
- Swipe UP richiude

**Logica LOOP:**
- `repetitions = 1` → label `LOOP`
- `repetitions = N` (N>1) → label `LOOP · N`
- `repetitions = -1` → label `LOOP · ∞`

### Stati Vista LIVE

| Stato | Trigger | Comportamento |
|---|---|---|
| Play normale | In esecuzione | Tutto visibile, tutto attivo |
| Count-in | Prima play nuova canzone | Countdown 4→1 nel teleprompter. Slot attivi. Counter "— / —". Prev/next/loop/stopBT disabilitati. |
| Count-in interrotto | STOP durante count-in | → Standby. Nessun overlay, nessun messaggio. |
| Loop attivo | Tap loop / MIDI | Macro bar ferma sull'ultimo segmento. Label `LOOP·∞`. |
| Standby | Fine canzone / tra canzoni | Vista sbiadita opacity 10%. Nome canzone successiva centrato (paddingTop 230px), pulse sine 2.2s (0.45→1.0). Tap ovunque o MIDI → parte. Transport opacity 0.4 tranne EMERG. POI vuota. |
| Fine setlist | Fine ultima canzone | "FINE SETLIST" al centro. Tasti: "TORNA A SETLIST" + "RICOMINCIA". PLAY disabilitato. |
| Stopped | Stop manuale | Slot spenti. Counter/barre/teleprompter congelati. Label "STOP" nell'header. Transport tutto attivo. |
| Overlay STOP | STOP durante play | Due tasti: "Riprendi da [nome sezione]" / "Dall'inizio [nome canzone]". Rimane fino a scelta esplicita. |
| FINE · NEXT SONG | Ultima sezione canzone | Zona POI mostra `FINE · NEXT SONG: {nome}` uppercase |

### Invarianti Vista LIVE

- Passaggio sezione: clock C++ — MAI timer SwiftUI
- Count-in: solo tra canzoni, mai tra sezioni. BPM = prima sezione canzone target
- Feedback visivo beat: callback C++ → dispatch main via PassthroughSubject — MAI timer SwiftUI
- `Section.name`: teleprompter. `Section.notes`: solo Studio, mai in Vista LIVE
- `repetitions = -1`: sentinel loop infinito
- Sfondo: `#0e0e10`

**Header:** nome canzone JBMono 700 28px + BPM + time sig + tasto ≡ SCALETTA + 3 LED

- Nome: Inter 500/700, 30px
- Reps: JBMono 600, 22px

**Separatori colorati:** riga orizzontale colorata tra sezioni. Colore libero (palette utente). Label facoltativa JBMono 18px centrata. Illimitati per canzone. Creati in Editor Canzone.

**Footer:** ■ STOP BASE (rosso 44px) + ↺ VISTA LIVE + VISTA LISTA (affiancati)

**Auto-scroll:** dopo ~1 minuto scorre lentamente verso parte centrale/finale.

## Invarianti tecnici Layer 3 — INVIOLABILI

| Regola | Dettaglio |
|---|---|
| Feedback visivo beat | Callback C++ → dispatch main via `PassthroughSubject` — MAI timer SwiftUI |
| `beatTickSubject` | `PassthroughSubject<Int, Never>` — MAI `@Published Double` per tick |
| `if isBeat` non `guard...continue` | Il `continue` rompe schedulazione audio subdivision |
| Cambio BPM sezione | `scheduleBPMChange` — sample-accurate al downbeat |
| `setBPM` vs `scheduleBPMChange` | `setBPM` = immediato (UI/Link/tap). `scheduleBPMChange` = cambio sezione |
| Backtrack | `AVAudioPlayerNode` in `AVAudioEngine` — MAI `AVPlayer` |
| Streaming backtrack | VIETATO |
| Route change | Clock C++ non si ferma |
| `midi_engine_start()` | Solo in `init()` — MAI in `start()`. Spostato dopo `setupGraph()` |
| `midi_engine_stop()` | RIMOSSO da `stopSync()` — MIDI sempre attivo |
| `os_log` | Unico debug — `print()` non catturato da iMazing |
| `@Published` assignment | ESCLUSIVAMENTE su `DispatchQueue.main.async` |
| `UIBackgroundModes: audio` | In `project.yml` — non toccare |
| Portrait | v1 — landscape rimandato a v2 |
| `SwiftUI.Section` | Qualificare sempre fino a TD-1 risolto |
| DebugView | Solo `#if DEBUG` — mai in produzione |
| RT thread | Zero malloc/free/new/delete/ARC/ObjC/mutex/I-O |
| `MetSlotStripView` contratto | Riceve `pattern: [String]` e `beatActive: Int`. MAI riferimento diretto ad `AudioEngine` |
| `currentAccentPattern` mapping | `2→"accent"`, `1→"beat"`, `0→"subdiv"`. Conversione `[UInt8]→[String]` in LiveView |
| `totalBarsInSection` | Legge `repetitions`, NON `beatsPerBar` |
| Glyph STOP | Sempre "■" — mai "⏹" |
| Mute click UI | SVG speaker — mai emoji |
| `RubberBtnView` | Parametro `accentColor: Color? = nil` — colore custom. Default nil = invariato |
| Link — init silente | `ABLLinkSetActive(false)` subito dopo `ABLLinkNew` — nessun peer senza toggle utente |
| Link — fresh play branching | Modello a 3 rami in `AudioEngine.swift::start()`: `peers==0 && !isPlaying` → `link_engine_start_at_beat_zero` (standalone, Q-BEATS detta). Altrimenti → `link_engine_join_running_session` con quantized launch al downbeat (Q-BEATS si adegua, NESSUN RequestBeatAtTime). Resume → `link_engine_start_at_beat`. Doc Ableton: "chi entra si adegua, chi c'è già non si muove" — "già nella sessione" significa "presente", NON "in play". Build #309 |
| Link — `start(resumeAtBeat:)` | Parametro `skipLinkWait` rimosso definitivamente. La distinzione standalone/shared avviene via probe atomica + `link_engine_num_peers()`. Vecchio DOWNBEAT WAIT (Opzione B) rimosso. Build #309 |
| Link — preference pane | `ABLLinkSettingsSheetView` sempre accessibile: Button "Impostazioni Ableton Link" in `SettingsView` visibile quando `linkEnabled == true`. Compliance LinkKit. Commit `a5451bd`. Ratificato 07/05/2026 |
| `isIdleTimerDisabled` | Gestione centralizzata sulla root view via `onChange(of: scenePhase)`: `true` se `phase == .active`, `false` altrimenti. NESSUN set in `AudioEngine.start()` o `stopSync()`. Schermo sempre acceso quando Q-BEATS è in foreground (use case live, coerente con Soundbrenner). Nessuna opzione configurabile in Settings. Ratificato 07/05/2026 |
| `Bridge MIDIEngineBridge.h` | Singola sorgente di verità. Disallineamento con `MIDIEngine.mm` = build rossa |
| Count-in BPM | Prima sezione canzone target — MAI BPM canzone uscente |
| TempoMap | Campo opzionale in BacktrackFile. `nil` = BPM fisso invariato. Zero regressioni |
| La backtrack comanda | In modalità adaptive la sorgente di verità è la TempoMap, non il BPM utente |
