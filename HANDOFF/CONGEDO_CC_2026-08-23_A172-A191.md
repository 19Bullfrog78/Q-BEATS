In A182 ho dichiarato **501 CR** su un file che ne ha **zero**. Il pattern CR arriva a grep
**vuoto**, e un pattern vuoto matcha ogni riga.
```
grep -c $'\r' FILE        → 501  (= numero di righe)     ⛔ MENTE
printf 'a\nb\n' | grep -c $'\r' → 2  su input SENZA CR   ⛔ prova che mente
tr -cd '\r' < FILE | wc -c → 0                            ✅ vede
```

✅ **Cura: solo sonde a byte** — `tr -cd '\r' | wc -c`, o l'aritmetica `wc -c` meno `tr -d`.
